# نسخة BAZEZ المنظّمة

هذه نسخة عمل منفصلة عن الموقع المنشور، مبنية على ملفات فرع `main` الحالية.

## التغييرات

- نقل تنسيقات الصفحة المضمّنة إلى `styles.css` و`page-overrides.css`.
- نقل كود الصفحة المضمّن إلى `menu-app.js` مع الحفاظ على ترتيب التحميل الأصلي.
- الإبقاء على `restaurant-system.js` و`menu-content.js` و`menu-images.css` وملفات إعداد قاعدة البيانات.
- الإبقاء على صور المنيو الـ19 كما هي؛ ملفات الصور تطابق نسخ GitHub. الصور مضغوطة بصيغة JPEG والصفحة تستخدم التحميل الكسول للمعرض، لذلك لم أعد ضغطها لتجنب فقدان وضوح التفاصيل.
- لم أغيّر السلوك أو الألوان أو ترتيب الواجهة. لم أزل أي كود مشتبهًا بأنه غير مستخدم لأن الواجهة تعتمد على أحداث HTML وأسماء تُنشأ وقت التشغيل.

## التحقق

- اجتازت ملفات JavaScript الثلاثة فحص الصياغة باستخدام Node.js.
- اجتازت الروابط المحلية وترتيب تحميل CSS وJavaScript فحصًا آليًا.
- راجعت مخطط Supabase ووجود وظائف حفظ الطلب وتتبع حالته والإدارة. كل جداول `public` الظاهرة في الفحص مفعّل عليها RLS، ووظيفة `place_order` تحفظ القسم مع كل صنف.
- لم أرسل طلبًا تجريبيًا إلى قاعدة البيانات الحية حتى لا أضيف طلبًا أو أغيّر المخزون.
- لم أتمكن من إجراء معاينة مرئية للمتصفح: سياسة أمان المتصفح منعت فتح نسخة العمل المحلية. لم أرفع هذه النسخة إلى الموقع الحي.
